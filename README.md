# Handmade (手作) 🥖✨

> **“面团在呼吸，时间在歌唱。”**
>
> **Handmade** 是一款专为烘焙爱好者（特别是女生们）设计的面包发酵记录与成本计算的 iOS PWA 应用程序。它融合了现代**液态玻璃态（Liquid Glassmorphism）**的治愈系美学设计，在温暖柔和的流体光影中，帮您忠实记录每一次与面粉、水和温度起舞的手作旅程。

---

## 🎨 视觉与交互美学 (UI/UX)
- **液态玻璃态美学**：背景中缓缓流动着粉紫、粉橘、水绿色的柔和流体，卡片面板使用毛玻璃质感（Backdrop Blur），搭配反光边框和圆角设计，营造出温暖、轻盈、高级的烘焙仪式感。
- **iOS 级丝滑交互**：底部的导航栏以及展开的抽屉卡片，完美贴合 iOS 的交互直觉，给您如同原生 App 般的使用体验。

---

## 🍞 核心特色功能
1. **智能烘焙百分比换算** ⚖️
   - 支持以高筋面粉为 **100%** 的烘焙百分比自动换算。
   - 修改面粉克重，其他配料克重自动按比例缩放；反之，修改其他配料克重也会自动反推百分比。
   - 支持 **0.5x（减半）/ 1.0x（单倍）/ 1.5x / 2.0x（双倍）** 等配方一键倍率缩放。
   
2. **手作发酵节奏与计时器** ⏱️
   - 预设标准发酵节奏：`水解` -> `揉面` -> `主发酵` -> `折叠翻面` -> `整形松弛` -> `二发` -> `烘烤`。
   - 动态发酵时间轴，当前步骤高亮闪烁，支持一键跳过或进入下一步。
   - **离线提示音**：计时结束时，利用 Web Audio API 离线合成温和的双频提示铃声，即使在厨房没网、静音状态也能贴心提醒。
   - 记录发酵时的室内**温度 (°C)** 和**湿度 (%)**，帮您总结最佳发酵环境。

3. **成品美图拍照与打分日记** 📸
   - 一键调起手机相机，记录金黄酥脆的表皮与丰富的切面组织。
   - **前端智能图片压缩**：自动利用 HTML Canvas 在设备本地进行图片压制，确保清晰的同时节省手机存储空间。
   - 5星打分系统与风味笔记，写下每一次手作的惊喜。

4. **单价成本核算器** 💰
   - 灵活的原料单价库，设置您的面粉、黄油、酵母等每千克单价。
   - 自动在配方和结账页算清这一炉面包的原材料成本，做到心中有数。

5. **100% 隐私安全与数据备份** 🛡️
   - **纯本地存储**：数据和照片全部保存在您手机浏览器的 IndexedDB 数据库中，不经过任何第三方服务器，100% 保护您的隐私。
   - **数据备份与恢复**：支持一键导出包含配方、日记和照片的 JSON 备份文件，并可以随时导入恢复。

## 📲 iOS 快捷安装指南（无需 App Store）

由于项目基于 **PWA（渐进式 Web 应用）** 技术构建，无需通过 App Store，也无需开通付费开发者账号，即可直接“安装”在 iOS 设备上：

1. 使用 iPhone 自带的 **Safari 浏览器** 打开本项目部署好的网页链接。
2. 点击屏幕底部导航栏正中央的 **“分享”** 按钮（向上箭头的正方形图标）。
3. 往下滑动菜单，选择 **“添加到主屏幕” (Add to Home Screen)**。
4. 在右上角点击 **“添加”**。
5. 此时手机桌面上就会多出一个精美手作图标的 **Handmade** App，点击即可全屏流畅体验！

## 🚀 开发者与部署指南

如果您想自己托管或分享给朋友，可以通过 **GitHub Pages** 获得免费的在线链接：

### 1. 本地运行与测试
在项目根目录下，使用 Node.js 运行一个静态服务器即可预览：
```bash
# 使用 http-server 快速运行
npx http-server -p 8080
```
在浏览器中打开 `http://localhost:8080` 即可测试。

### 2. 部署到 GitHub Pages
1. 将此仓库代码推送至您的 GitHub 账号下。
2. 打开 GitHub 仓库页面，点击 **Settings** (设置) -> **Pages**。
3. 将 **Build and deployment** 下的 Branch 设置为 `main` 分支，路径选择 `root`，然后点击 **Save**。
4. 等待 1 分钟左右，您就可以获得一个公网专属的 HTTPS 网址（例如 `https://<your-username>.github.io/Handmade/`），分享给朋友即可。
